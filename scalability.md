# Scalability

## Progressive Architecture

```text
PROTOTYPE
   ↓
9-ARM SYSTEM
   ↓
MULTI-BUOY NETWORK
   ↓
REGIONAL MONITORING
```

## Stage 1 — Prototype

Purpose:

- Demonstrate wave-energy harvesting concept
- Validate sensor integration
- Demonstrate energy management
- Demonstrate dashboard and system-health monitoring

## Stage 2 — 9-Arm System

Purpose:

- Parallelized wave-energy harvesting
- Higher installed generator capacity
- Modular arm replacement
- Common central hub architecture

The current scalable engineering configuration uses **9 arms** with a **75 W rated generator per arm**.

## Stage 3 — Multi-Buoy Network

Multiple autonomous nodes can provide:

- Distributed sensing
- Spatial environmental observations
- Event-based communication
- Remote system-health visibility

## Stage 4 — Regional Monitoring

A network of buoy nodes can support wider polar/ocean monitoring coverage.

This stage requires field qualification, communication infrastructure, environmental testing and deployment planning.

## Scalability Principle

The key architectural advantage is modularity:

**Common hub + modular arms + common electronics architecture**

This allows the system to evolve without redesigning the complete platform at every deployment scale.

## Important Boundary

Scalability is an engineering architecture concept in the current project. Regional field performance remains subject to prototype testing, environmental qualification and deployment validation.
